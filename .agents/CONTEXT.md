# Professional Portfolio

Public portfolio presenting Michael Muniz as an experienced backend software
engineer through verified professional outcomes and selected personal context.

## Language

**Impact Story**:
An outcome-focused account of professional work, grounded in the current resume
or another verified public source. It replaces the old portfolio's side-project
showcase and does not imply ownership of an employer's product.
_Avoid_: Project, portfolio project

**Career Timeline**:
A concise chronological record of verified roles, employers, and dates. It
supports the Impact Stories without repeating full resume bullets.
_Avoid_: Resume section

**Personal Signal**:
A brief detail showing character outside employment: Arch Linux, teaching
coding, or playing video games. Video-game interest must not be described as
game-development work or ambition.
_Avoid_: Game developer, game-development interest

**Availability**:
Michael is currently open to backend or platform engineering opportunities and
select contract work.
_Avoid_: Junior developer, unavailable

## Flagged Ambiguities

- **Project**: refers only to implementation work inside this repository. Public
  professional narratives use Impact Story so employer work is not presented as
  a personal project.
